# clips/

데모 화면 녹화본을 여기에 넣는다. 파일명이 고정되어 있다.

| 파일명 | 내용 | 최소 길이 |
|---|---|---|
| `adnova.mp4`  | 상품 사진 업로드 → 무드 선택 → 광고 이미지 생성 | 14초 |
| `bidmate.mp4` | 질의 입력 → 검색 결과 → 근거 문서 | 12초 |
| `forg.mp4`    | 텔레그램에 공시 카드가 도착 | 10초 |

- 없으면 해당 구간은 플레이스홀더로 렌더링된다(구성 확인용).
- 클립이 씬보다 짧으면 자동으로 루프된다.
- 권장: 1600×1000 이상 / 30fps / H.264 mp4.
- 업로드 전 화면에 API 키·토큰·실명 계정이 보이지 않는지 확인할 것.

mp4는 `.gitignore`로 제외되어 있다. 필요하면 Git LFS를 쓰거나 GitHub 첨부 URL로 올린다.
