# 60초 포트폴리오 영상 — 컷시트

**전제 (읽고 시작할 것)**

- 60초에 "나의 모든 것"은 안 들어간다. 물리적 한계는 **메시지 1개 + 증거 3개**다.
- 이 영상은 **이력서 대체가 아니라 훅**이다. 국내 AI 엔지니어 채용의 서류 스크리닝은 문서 기반이므로,
  이력서/포트폴리오 PDF는 그대로 두고 영상은 README 최상단·LinkedIn 피처드에 얹는 용도로 쓴다.
- 선택한 메시지: **"낯선 도메인을 파고들어, 데이터로 판단하고, 서비스로 완결한다."**
- 선택한 증거 3개: AdNova(DINOv2 0.34→0.80) / BidMate(12개 조합 비교, Hit@5 0.91) / forG(푸시 판단).

## 필요한 소재 (직접 준비해야 하는 것)

`clips/` 폴더에 아래 3개를 넣으면 데모 구간에 자동 합성된다. 없으면 플레이스홀더가 그대로 렌더링된다.

| 파일 | 내용 | 최소 길이 | 촬영 지침 |
|---|---|---|---|
| `clips/adnova.mp4` | 상품 사진 업로드 → 무드 선택 → 광고 이미지 생성까지 | 14초 | 생성 대기 시간은 잘라내고 **결과가 나오는 순간**을 반드시 포함. 마우스 이동은 느리게. |
| `clips/bidmate.mp4` | 질의 입력 → 검색 결과 → 근거 문서 하이라이트 | 12초 | 답변 텍스트가 스트리밍되는 장면이 있으면 그 구간을 쓴다. |
| `clips/forg.mp4` | 텔레그램에 공시 카드가 도착하는 화면 | 10초 | 세로 화면이면 좌우 여백은 자동으로 crop된다(`object-fit:cover`). 알림이 **뜨는 순간**을 포함. |

- 권장 스펙: 1600×1000 이상, 30fps, H.264 mp4. 화면 녹화 그대로면 충분하다.
- 개인정보(실명 계정, 이메일, 토큰, API 키)가 화면에 보이지 않는지 확인할 것.
- README에 이미 올려둔 GitHub 첨부 영상을 그대로 내려받아 써도 된다.

## 렌더링

```bash
cd video
python3 render.py                       # 60초, 1920x1080, 30fps
python3 render.py --cut 30              # 30초 컷
python3 render.py --w 960 --h 540 --fps 15 --out out/preview.mp4   # 빠른 확인용
```

브라우저에서 `portfolio.html`을 열면 재생/스크럽/30초 전환이 되는 미리보기가 나온다.
문구 수정은 `portfolio.html`의 각 `<section class="scene">` 안에서 하면 되고, 씬 길이는 상단 `CUTS` 상수에서 조정한다.

## 음악 / 나레이션

- **음악을 넣을 거면 저작권 확인이 끝난 것만 쓸 것.** YouTube Audio Library, Pixabay Music 등.
  채용 담당자에게 보내는 영상에 무단 사용 음원이 붙어 있으면 그 자체가 감점 요인이다.
- 나레이션을 녹음할 경우: 마이크는 입에서 15cm, 한 문장씩 끊어 녹음, 씬 경계에 맞춰 배치.
- 넣지 않아도 성립한다. **음소거 자동재생 환경(LinkedIn 피드, GitHub README)이 기본값**이므로 자막이 본체다.
