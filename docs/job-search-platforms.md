# 이직 준비할 때 꼭 보는 채용사이트 총정리

> 대기업 · 중견기업 · 스타트업 · 외국계 + 이직 제안까지

채용공고를 찾을 때 사람인, 잡코리아만 보고 계셨다면 생각보다 활용할 수 있는 채용 플랫폼이 정말 많아요. 특히 경력직이라면 **내가 직접 공고를 찾아 지원하는 것뿐만 아니라, 이력서/프로필을 등록해두고 기업이나 리크루터에게 먼저 제안을 받는 방법**도 같이 활용해보세요.

목적에 맞게 나눠 쓰는 게 편합니다.

- **① 공고를 직접 찾는 사이트**
- **② 이력서를 올려두고 제안받는 사이트**
- **③ 외국계에 특화된 사이트**

## ⭐ 01. 이력서 올려두고 이직 제안받기

### 1. 리멤버 | 경력직이라면 우선 등록 ⭐⭐⭐⭐⭐

**추천 대상:** `경력직` `대기업` `중견기업` `스타트업` `스카웃`

🌐 [www.rememberapp.co.kr](https://www.rememberapp.co.kr) (모바일앱)

리멤버는 단순히 채용공고만 보는 것보다 **프로필을 등록해두고 스카웃 제안을 받는 용도**로 활용하기 좋아요. 2026년 7월 기준 누적 스카웃 제안이 1,300만 건을 넘었다고 안내하고 있어요.

**💡 활용 TIP**

- 최근 경력까지 빠짐없이 업데이트
- 담당 업무만 나열하지 말고 **성과까지 작성**
- 직무 관련 키워드를 구체적으로 작성
- 프로젝트/성과는 가능하면 숫자로 표현
- 당장 이직하지 않더라도 프로필을 만들어두기

👉 경력직이라면 개인적으로 가장 먼저 프로필을 만들어둘 만한 곳

### 2. 원티드 | 스타트업·테크 이직

**추천 대상:** `스타트업` `테크` `플랫폼` `경력직`

🌐 [www.wanted.co.kr](https://www.wanted.co.kr)

스타트업이나 테크·플랫폼 기업까지 폭넓게 보고 싶을 때 같이 체크하기 좋은 사이트예요.

**💡 활용 TIP**

- 관심 직무를 하나의 단어로만 검색하지 않기
- 비슷한 직무명을 여러 개 검색
- 관심 기업 저장
- 경력 프로필 최신 상태 유지
- 마음에 드는 회사가 당장 채용하지 않아도 주기적으로 확인

## 🌎 02. 외국계 취업이라면 꼭 체크

### 3. LinkedIn | 외국계·글로벌 이직 ⭐⭐⭐⭐⭐

**추천 대상:** `외국계` `글로벌 기업` `해외취업` `경력직` `리크루터`

🌐 [www.linkedin.com/jobs](https://www.linkedin.com/jobs)

외국계까지 생각한다면 LinkedIn 프로필도 만들어두는 걸 추천해요. **Open to Work**를 설정해 관심 직무와 근무지역 등을 표시하고, 리크루터에게 새로운 기회에 열려 있다는 신호를 줄 수 있어요.

**💡 프로필 작성 TIP**

단순히 `Marketing Manager`라고만 쓰기보다는 **직무 + 전문영역 + 핵심역량**이 한눈에 보이도록 작성해보세요. 외국계 지원 예정이라면 영문 프로필도 꼼꼼하게 작성하기!

### 4. 피플앤잡 | 외국계 전문 ⭐⭐⭐⭐⭐

**추천 대상:** `외국계` `헤드헌팅` `경력직`

🌐 [www.peoplenjob.com](https://www.peoplenjob.com)

외국계 취업을 생각한다면 따로 챙겨볼 만한 사이트. 이력서를 등록하면 외국계 기업이나 헤드헌터를 통한 입사 제안을 받을 수 있습니다.

> **💡 외국계 준비 추천 조합:** LinkedIn + 피플앤잡

### 5. Glassdoor | 해외기업 조사까지

**추천 대상:** `해외취업` `글로벌 기업` `외국계` `기업정보`

🌐 [www.glassdoor.com](https://www.glassdoor.com)

해외 기업 채용공고를 찾으면서 **기업 리뷰·연봉 등의 정보를 함께 조사할 때** 활용하기 좋아요.

## 🏢 03. 대기업·중견기업 공고 찾기

### 6. 잡코리아

**추천 대상:** `대기업` `중견기업` `중소기업` `신입` `경력`

🌐 [www.jobkorea.co.kr](https://www.jobkorea.co.kr)

국내 채용공고를 폭넓게 확인할 때 기본적으로 체크하기 좋은 종합 채용 플랫폼.

**💡 활용 TIP:** 관심 기업을 하나씩 검색하는 것보다 `직무 + 경력연차 + 지역` 조건을 설정해놓고 보는 게 훨씬 편해요.

### 7. 사람인

**추천 대상:** `대기업` `중견기업` `중소기업` `신입` `경력`

🌐 [www.saramin.co.kr](https://www.saramin.co.kr)

잡코리아와 함께 기본적으로 확인해볼 만한 국내 종합 채용 플랫폼. 사람인·잡코리아는 단순히 공고만 보는 용도로 끝내지 말고 **이력서/프로필도 최신 상태로 관리**해보세요.

### 8. 인크루트 | 국내 종합 채용 플랫폼

**추천 대상:** `대기업` `중견기업` `중소기업` `신입` `경력`

🌐 [www.incruit.com](https://www.incruit.com)

사람인·잡코리아와 함께 국내 채용공고를 폭넓게 찾아볼 때 활용할 수 있는 종합 채용 플랫폼이에요.

한 사이트에 모든 채용공고가 올라오는 건 아니기 때문에 **여러 종합 채용사이트를 함께 확인하는 방식**도 추천해요.

**💡 활용 TIP**

- 관심 직무별 채용공고 확인
- 신입·경력 공고 모두 탐색
- 사람인·잡코리아와 공고 교차 확인
- 관심 기업의 새로운 채용 여부 주기적으로 체크

👉 국내 채용공고 탐색 범위를 넓히고 싶다면 추가

단순히 채용공고만 보는 것뿐 아니라 **기업정보와 기업분석 콘텐츠를 함께 확인할 수 있다는 점**이 장점이에요.

👉 특히 대기업·중견기업 취준생에게 추천

## ✨ 그래서 뭘 먼저 해야 할까요?

### 💌 BONUS 1. 이직 제안을 받고 싶다면

이력서를 등록했다고 무조건 좋은 제안이 오는 건 아니에요. 기업이나 리크루터가 내 프로필을 봤을 때 **"이 사람이 무슨 일을 잘하는 사람인지"** 빠르게 알 수 있어야 해요.

### 💡 BONUS 2. 프로필에 꼭 넣어볼 것

| | 항목 | 예시 |
| :---: | :--- | :--- |
| **①** | **정확한 직무명** | 시장에서 많이 사용하는 직무 키워드도 함께 확인 |
| **②** | **숫자로 표현 가능한 성과** | 매출 / 성장률 / 고객 수 / 프로젝트 수 / KPI / 전환율 |
| **③** | **사용 가능한 툴** | Excel / SQL / GA4 / Figma / Salesforce |
| **④** | **최근 프로젝트** | 몇 년 전 경험만 자세하고 최근 경험이 비어 있지 않도록 업데이트 |
| **⑤** | **가고 싶은 직무의 키워드** | 채용담당자가 검색할 법한 키워드 확인 |

### 📌 BONUS 3. 이직할 때 추천하는 루틴

1. 리멤버·원티드·LinkedIn 등 필요한 플랫폼에 프로필 등록
2. 사람인·잡코리아 등에서 관심 직무 채용공고 확인
3. 관심 기업이 생기면 **그 기업의 공식 채용 홈페이지도 반드시 확인**
4. 외국계라면 LinkedIn + 피플앤잡 추가 확인
5. 마음에 드는 공고를 발견하면 기업 홈페이지·잡플래닛 등 여러 경로로 회사 조사
6. 지원 후에도 프로필은 그대로 유지하고 새로운 제안 확인

## 🤍 마지막으로

이직할 때 중요한 건 **내가 좋은 회사를 찾는 것만은 아니에요.**
