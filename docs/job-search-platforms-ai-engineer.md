## 🎯 전제: 나는 어떤 트랙에 있는가

AI 엔지니어 구직에서 채널 선택은 **"신입이냐 경력이냐"보다 "공채 트랙이냐 수시채용 트랙이냐"**로 갈립니다.

| | 공채 트랙 | 수시채용 트랙 |
| :--- | :--- | :--- |
| **주 대상** | 대기업 신입 공채, 인턴 | 테크 기업·스타트업 상시 포지션 |
| **시기** | 상·하반기 시즌 집중 | 연중 상시 |
| **평가 축** | 자소서 · 인적성 · 코테 | **포트폴리오 · 기술 인터뷰** |
| **주요 채널** | 캐치, 자소설닷컴, 기업 공채 페이지 | 원티드, 점핏, 프로그래머스 커리어, 랠릿, LinkedIn |

**직무 전환 경력자(기획·운영 경력 + AI 엔지니어링 역량)라면 수시채용 트랙이 주력입니다.** AI 포지션은 대부분 상시 채용이고, 평가가 자소서보다 **"뭘 만들어서 굴려봤는가"**에 쏠려 있어요. 이미 라이브 서비스 3개(AdNova·BidMate·forG)를 가지고 있다면 공채 트랙보다 여기서 훨씬 유리합니다.

> 💡 공채 트랙(캐치·자소설닷컴)은 **대기업 AI 조직의 신입/영입 전형이 열릴 때만 보조로** 쓰면 충분합니다. 주력으로 삼을 채널은 아니에요.

## 🅰️ A. 주력 채널 — AI/개발 직무 특화

### 1. 원티드 ⭐ 주력

🌐 [www.wanted.co.kr](https://www.wanted.co.kr)

국내 AI/ML 포지션이 가장 많이 모이는 곳. 머신러닝 엔지니어 직무 카테고리가 따로 있고, 스타트업부터 대형 테크까지 폭이 넓습니다.

**💡 이 직무 기준 활용법**

- 직무명을 **하나로 검색하지 마세요** — 같은 일이 회사마다 다르게 불립니다
  `AI 엔지니어` `ML 엔지니어` `LLM 엔지니어` `MLOps` `AI 리서치 엔지니어` `Applied Scientist` `생성형 AI` `RAG` `백엔드(AI)`
- **기술 스택 태그로도 검색** — `LangChain` `PyTorch` `Diffusion` `vLLM` `RAG` `FastAPI`
- 합격보상금·추천 기능이 있어 지인 추천 경로를 같이 쓰면 서류 통과율이 올라갑니다

### 2. 점핏 ⭐ 주력

🌐 [jumpit.saramin.co.kr](https://jumpit.saramin.co.kr)

사람인이 운영하는 **개발자 특화** 플랫폼. 사람인 본체와 공고 풀이 다르니 따로 봐야 합니다.

**💡 활용법:** **기술 스택 기준 필터링**이 핵심 강점이에요. 직무명이 아니라 `Python` `PyTorch` `Docker` `GCP` 같은 스택으로 걸어두면 직무명이 애매한 공고까지 잡힙니다.

### 3. 프로그래머스 커리어 ⭐ 주력

🌐 [career.programmers.co.kr](https://career.programmers.co.kr)

프로필의 **기술 태그·희망 직무·경력을 기반으로 포지션을 추천**해주고, 기업에서 오는 제안도 받을 수 있습니다. 프로필 완성도가 올라갈수록 추천 정확도가 좋아지는 구조예요.

**💡 부가 가치:** 코딩테스트·과제테스트 연습 문제가 같은 플랫폼에 있습니다. 국내 다수 기업이 여기서 코테를 출제하므로, **지원 채널이자 코테 대비 채널**로 겸용하세요.

### 4. 랠릿 (Rallit)

🌐 [www.rallit.com](https://www.rallit.com)

인프랩(인프런)이 운영하는 IT 전문 커리어 플랫폼. 개발·디자인·기획 포지션 중심이고, 프로필 등록 후 제안을 받는 구조도 지원합니다. 원티드·점핏에 없는 공고가 종종 있어요.

### 5. LinkedIn ⭐ 주력

🌐 [www.linkedin.com/jobs](https://www.linkedin.com/jobs)

AI 직군에서는 **외국계 전용이 아니라 국내 채용에서도 주력 채널**입니다. 국내 테크 기업·AI 스타트업의 리크루터가 실제로 여기서 사람을 찾아요.

**💡 이 직무 기준 활용법**

- **Open to Work 설정** — 관심 직무(AI/ML Engineer), 근무지, 원격 여부까지 지정
- 헤드라인을 직함만 쓰지 말고 **직무 + 전문영역 + 검증 근거**로
  ❌ `AI Engineer`
  ⭕ `AI Engineer · Generative AI & LLM/RAG · 라이브 서비스 3건 배포 (GCP)`
- **GitHub 링크를 프로필 상단에 배치** — AI 직군은 이게 이력서 역할을 합니다
- 관심 기업의 AI 팀 구성원·테크리드를 팔로우 → 공고 뜨기 전에 팀 동향이 보입니다
- 영문 프로필 병행 (외국계·해외 리모트 포지션 대비)

## 🅱️ B. 프로필 걸어두고 제안받기

### 6. 리멤버

🌐 [www.rememberapp.co.kr](https://www.rememberapp.co.kr) (모바일 앱)

2025년 11월 기준 누적 스카웃 제안 1,000만 건 돌파, 매출 상위 1,000대 기업 중 약 90%가 활용한다고 발표했습니다.

**💡 직무 전환자에게 특히 유용한 이유**

리멤버는 **이전 경력(기획·운영) 기반 제안**과 **현재 직무(AI) 기반 제안**이 둘 다 들어옵니다. 이게 단점이 아니라 기회예요 — **AI 프로덕트 조직**에서는 "도메인을 아는 엔지니어"를 따로 찾습니다.

- 프로필에 이전 경력을 지우지 말고, **AI 역량과 연결되게** 서술
  예) `공공 배달 플랫폼 기획 2년 → 공공조달 RAG 시스템 직접 구축`
- 희망 직무를 AI 엔지니어로 명확히 설정하되, 도메인 키워드도 함께 노출
- 원하지 않는 방향의 제안이 와도 **시장이 나를 어떻게 읽는지**에 대한 신호로 활용

## 🅴 E. 기업 공식 채용 페이지 — 가장 중요한 채널

**AI 포지션은 플랫폼에 올라오기 전에 자사 채용 페이지에 먼저 뜨고, 아예 안 올라오는 경우도 많습니다.**

가고 싶은 회사가 정해졌다면 플랫폼을 기다리지 말고 **채용 페이지를 직접 주 1회 확인**하거나 **채용 알림을 구독**하세요.

**추적 대상 예시 (AI 조직이 있는 곳)**

- **대형 테크** — 네이버 / 카카오 / LINE / 쿠팡 / 배달의민족(우아한형제들) / 토스 / 당근
- **AI 전문** — 업스테이지 / 뤼튼 / 스캐터랩 / 라이너 / 딥브레인AI / 마키나락스 / 코난테크놀로지
- **대기업 AI 조직** — LG AI연구원 / 삼성리서치 / SKT AI / 네이버클라우드 / KT

**💡 도메인 경험을 살릴 수 있는 곳을 우선순위에 두세요** — 공공조달·금융/공시·소상공인 도메인 경험은 해당 버티컬 AI 회사(레그테크, 공공 SI의 AI 조직, 커머스·SMB SaaS)에서 **다른 지원자가 못 가진 차별점**이 됩니다.

## 🧩 이 직무에서 진짜 중요한 것: 채널보다 자산

AI 엔지니어 채용은 **공고를 얼마나 많이 봤는지보다, 발견됐을 때 보여줄 게 있는지**로 갈립니다. 아래 4개가 사실상 이력서입니다.

### ① GitHub — 최우선 자산

프로필 README가 곧 포트폴리오입니다. 채용담당자가 **30초 안에** 다음을 알 수 있어야 해요.

- 무엇을 만들었는가 (서비스 링크 · 데모)
- 어떤 판단을 왜 했는가 (기술 선택의 근거)
- 결과가 숫자로 있는가 (DINOv2 0.34→0.80, Hit@5 0.91 같은)
- 실제로 배포까지 갔는가

### ② 성과의 정량화

AI 직군에서는 "무엇을 썼다"보다 **"어떻게 검증했다"**가 변별력입니다.

| 약한 서술 | 강한 서술 |
| :--- | :--- |
| LangChain으로 RAG를 구현했습니다 | 임베딩 3종 × LLM 4종 = 12개 조합을 비교해 KURE-v1 + Phi-4-mini를 선정, Hit@5 0.91 달성 |
| 이미지 생성 모델을 적용했습니다 | 실패 유형을 분류해 프롬프트 구조·마스크로 개입, 제품 동일성 DINOv2 0.34 → 0.80 |
| 하이브리드 파이프라인을 구성했습니다 | 3암 비교 + 홀드아웃 검증으로 비용·속도 1위 안을 품질 예측 실패 근거로 기각 |

**"기각한 판단"은 특히 강한 신호입니다.** 수치가 좋아 보이는 걸 그냥 채택하지 않고 반증했다는 건, 시니어가 주니어에게서 가장 보고 싶어 하는 태도예요.
